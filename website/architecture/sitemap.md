# Sitemap

## Overview

OUTstanding Speakers is a speaker platform that connects organizations with people willing to share lived experiences that create meaningful workplace conversations.

The website has two main goals:

1. Build trust and communicate the value of lived-experience conversations
2. Help organizations discover and request the right speaker

The website supports two primary journeys:

- Discovery journey → understand the initiative and explore speakers/resources
- Booking journey → request a speaker session

---

## Primary Navigation

Main navigation:
