# Booking Confirmation Specification

## Purpose

The confirmation page is shown after a booking request is successfully submitted.

Its purpose is to reassure the user, clarify expectations and guide next steps.

This is not a booking confirmation.

It confirms that a request has been submitted for review.

---

## Primary Goals

1. Confirm successful request submission
2. Reinforce what happens next
3. Set expectations clearly
4. Reduce uncertainty
5. Maintain trust and emotional warmth

---

## User Questions

The confirmation page should answer:

- Was my request submitted successfully?
- Is the session confirmed?
- What happens next?
- When should I expect to hear back?
- What can I do now?

---



## Core Message

The key message should be:

Your request has been received.

The selected speaker will review:

- session context
- availability
- overall fit

The session is not confirmed yet.

---



## Messaging Tone

The page should feel:

- reassuring
- calm
- human
- warm
- professional

Avoid:

- transactional messaging
- overly generic success messages
- cold confirmation language

---



## Main Content



### Success State

Clear visual success feedback.

The success state should feel polished and confidence-building.

---



### Confirmation Headline

Headline should feel human and clear.

---



### Supporting Copy

The copy should explain:

- request submitted successfully
- speaker will review request
- confirmation comes later
- follow-up communication will happen soon

Example structure:

We’ve sent your request successfully.

The speaker will review your request, availability and session context before confirming next steps.

You’ll hear from us soon.

---



## Booking Summary

Show a summary of the request.

Possible fields:

- Speaker name
- Organization
- Session format
- Preferred date
- Audience type

Purpose:

- reassure users that the correct request was submitted

---



## Next Steps

Suggested next actions:

- Browse Resources
- Explore Speakers
- Return to Home

Optional:

- Download summary
- Receive confirmation email

---



## Emotional Design Notes

This page should feel like a calm pause after form completion.

It should create:

- relief
- confidence
- trust

This is an important emotional transition.

The user should leave feeling:

- supported
- informed
- confident about next steps

---



## Motion Notes

Motion can be slightly more expressive here.

Keep motion calm and premium.

---



## Success Metrics

The confirmation page succeeds when users:

- understand the request was submitted
- understand the session is not yet confirmed
- understand what happens next
- leave with low uncertainty
