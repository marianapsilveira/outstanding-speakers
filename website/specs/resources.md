# Resources Page Specification

## Purpose

The Resources page supports employees, managers and HR teams before, during and after speaker sessions.

Its purpose is to provide practical tools, guidance and learning materials that help conversations become more thoughtful, respectful and impactful.

This page reinforces that OUTstanding Speakers is not only about booking sessions. It also helps organizations create meaningful conversations with care.

---

## Primary Goals

1. Support conversation preparation

2. Help users navigate sensitive topics with confidence

3. Extend value beyond speaker sessions

4. Encourage continuous learning

Primary actions:

- Open Resource

- Explore Speakers

- Book a Speaker

---

## User Questions

The Resources page should answer:

- How do we prepare for meaningful conversations?

- How do we ask respectful questions?

- What should managers consider?

- How should HR support these conversations?

- What happens after the session?

---

## Page Structure

1. Page Intro

2. Resource Categories

3. Resource Library

4. Final CTA

5. Footer

- conversations benefit from preparation

# Interaction Notes

## Browsing Experience

The browsing experience should feel:

- structured

- calm

- easy to navigate

- supportive

Users should not feel overwhelmed by too much information.

---

## Filtering

Optional filters may include:

- Audience

- Topic

- Resource Type

Filtering should remain simple.

---

## Motion

Motion should be subtle and lightweight.

Examples:

- hover transitions

- smooth card interactions

- soft content reveals

---

# Content Principles

Resources should feel:

- practical

- respectful

- thoughtful

- easy to apply

Avoid:

- generic DEI content

- performative messaging

- overly academic language

- abstract theory without practical application

Resources should help users prepare with confidence and continue learning with intention.

---

# Success Metrics

The Resources page succeeds when users:

- find relevant guidance quickly

- engage with multiple resources

- feel more prepared for meaningful conversations

- continue toward speaker exploration or booking
