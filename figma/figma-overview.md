# Figma Overview

## Purpose

This file documents the current Figma prototype and how it should inform the website build.

The Figma prototype is the primary visual reference for OUTstanding Speakers.

---

## Prototype Status

Current status:

- Visual direction defined
- Main website pages designed
- Booking flow explored
- Brand atmosphere established

The design should be treated as the current source of truth for:

- visual style
- page structure
- interaction direction
- content hierarchy

---

## Designed Areas

Current Figma includes:

- Home page
- Speakers page
- Speaker profile
- Resources page
- Booking flow
- Confirmation state

---



## Visual Direction

The prototype uses:

- strong editorial layouts
- dark cinematic sections
- high-contrast typography
- video backgrounds from Pexels
- electric lime accents
- blue-violet gradients
- large immersive visual blocks

The experience should feel:

- modern
- premium
- human
- cinematic
- conversation-led

---



## Implementation Notes

Background videos should be treated as atmosphere, not content.

They must:

- preserve text readability
- load efficiently
- degrade gracefully
- not distract from the core message

---



## Figma Handoff Priorities

Before implementation, review:

- frame naming
- component naming
- typography styles
- color styles
- spacing consistency
- responsive behavior
- hover / motion notes
